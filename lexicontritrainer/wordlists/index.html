A simple text format

Create a list of your own.

Write one vocabulary entry per line. The text before each tag is its value; a word and at least one translation or definition are needed. Lines beginning with # are comments.

Example file

# Example English–Spanish wordlist
house<w>casa<t>a building used as a home<d>
learn<w>aprender<t>gain knowledge or skill<d>

<w> = word · <t> = translation · <d> = definition · <r> = optional root

A note about your files

Save the list as a UTF-8 text file with a .txt extension. You can use multiple lines for the same word to include more than one sense or translation.

Wordlists can be personal learning materials. Only publish lists that you have the right to share, and avoid putting private personal information in publicly downloadable files.

How to import a wordlist

Download

Save a .txt wordlist to your device using the browser.

Open the app

Open the LexiconTriTrainer file chooser and select Import a file.

Select and practise

Choose the downloaded file using Android's document picker, then open it to begin.
