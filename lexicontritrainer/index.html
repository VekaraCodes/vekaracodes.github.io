A simple text format

Create a list of your own.

Write one vocabulary entry per line. The text before each tag is its value; a word and at least one translation or definition are needed. Lines beginning with # are comments.

Example file

# Spanish definitions, English translations
esperar<w>aguardar que algo suceda<d>to wait, to hope<t>
espera<w>esperar<r>tiempo que se pasa aguardando algo<d>waiting, wait<t>
desesperar<w>esperar<r>perder la esperanza o la paciencia<d>to despair<t>

<w> = main word · <r> = optional root · <d> = target-language definition · <t> = English translations

How root groups work

The <r> tag links derivatives and closely related words into one learning group. Choose the most basic or logical word as the root, and use the exact same root value for every member.

For example, esperar is the root of espera and desesperar. The root word itself can omit <r>; without this tag, the main word becomes its own root.

To distinguish homonymous roots in the current app, use unique identifiers such as can_container<r>. The parser presently ignores parenthetical root labels such as can (container)<r> when grouping.

Save the file as UTF-8 .txt, one sense per line; you may repeat a word to describe several meanings. Use # at the start of a line for comments. Only publish wordlists you have the right to share.
