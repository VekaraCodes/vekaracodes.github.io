Wordlists

Start studying with ready-to-use dictionaries, or build your own.

  • Spanish, French & German — core vocabulary for everyday language learning
  • English Rare Word Dictionary — unusual and less common English words
  • Specialised collections — focused vocabulary for topics such as travel, abstract concepts, medicine and technical subjects

Download a list below or import your own plain-text vocabulary file through the app’s File menu. Core dictionaries stand alone; topic-specific lists let you practise particular fields.

Wordlist file format

Wordlists are UTF-8 .txt files with one entry per line. Write each value before its tag:

word<w>root<r>definition<d>translation<t>
  • <w>Word — the vocabulary item to learn (required)
  • <r>Root — optional; groups related words together
  • <d>Definition — an explanation in the language being studied
  • <t>Translation — one or more meanings, separated by commas

Each word needs a definition, a translation, or both. Without <r>, the word acts as its own root.

Parentheses and square brackets

These give two different kinds of help while studying:

  • (…)Context in the question. Parentheses distinguish meanings but are not part of the answer: can (container) → can; bank (river) → bank.
  • […]Extra information with the answer. Square brackets stay out of the question and appear when the answer is revealed: éclair [m] shows noun gender; arrive [in] shows a preposition.

For example, a wordlist could contain:

can (container)<w>metal container for food<d>lata<t>
éclair [m]<w>pâtisserie fourrée à la crème<d>cream-filled pastry<t>
arrive [in]<w>reach a destination<d>to arrive<t>
llegada<w>llegar<r>acción de llegar<d>arrival<t>

Use separate lines for different meanings of the same word. Lines beginning with # are comments. The starter template and full instructions cover more examples.
