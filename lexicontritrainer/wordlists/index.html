A simple text format

Create a list of your own.

Write one vocabulary entry per line. Put the text before its tag. Each line needs a main word and at least one definition or translation. Lines beginning with # are comments.

Example file

# Spanish definitions, English translations
esperar<w>aguardar que algo suceda<d>to wait, to hope<t>
espera<w>esperar<r>tiempo que se pasa aguardando algo<d>waiting, wait<t>
desesperar<w>esperar<r>perder la esperanza o la paciencia<d>to despair<t>

<w> = main word · <r> = optional root / word family · <d> = target-language definition · <t> = English translations

Simple rules

Use <w> for the main word, <d> for a definition in the target language, and <t> for English translations separated by commas.

The <r> tag is optional. Use it for derivatives and closely related words that should belong to the same word family. If you leave out <r>, the main word is used as the root automatically.

There can be several lines of the same word to cover different meanings. Extra notes can be placed in (parentheses) or [brackets]. Text inside brackets is revealed only when the correct answer is shown.

Save the file as a UTF-8 .txt file, one sense per line. Use # at the start of a line for comments.
