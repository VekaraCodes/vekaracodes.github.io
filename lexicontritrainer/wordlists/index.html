You can also create and import your own vocabulary files using the app’s File menu. More self-contained core dictionaries and topic-specific supplementary files are available below.

File format (simple overview)

Use a plain UTF-8 .txt file, with one word or meaning per line. Text comes before its tag:

word<w>root<r>definition<d>translation, translation<t>
  • <w>Main word — required
  • <r>Root — optional; groups related words
  • <d>Definition — in the language being learned
  • <t>Translation — English meanings separated by commas

A word needs at least a definition or a translation. If the root tag is omitted, the main word becomes its own root.

You may add explanatory notes in (parentheses) or [square brackets]. Text inside them is ignored when the app presents or checks an answer.

banco<w>asiento (para sentarse)<d>bench, seat<t>
cas[a]<w>edificio usado como vivienda<d>house, home<t>
espera<w>esperar<r>tiempo de esperar<d>waiting<t>

For several meanings of one word, use separate lines. Lines starting with # are comments. See the template for examples.
