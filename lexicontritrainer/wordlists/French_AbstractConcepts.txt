# FRENCH ROOT DICTIONARY — ABSTRACT & INTELLECTUAL SUPPLEMENT
# Companion to french_root_dictionary_SORTED.txt and french_tourist_supplement.txt.
# Same format, same principles:
#   word<w>root<r>definition in French<d>English translations<t>
# <r> is omitted when the word is itself the root of its group. The files share one root
# space: a root here may live in the main file (pesanteur<w>peser<r>, vécu<w>vivre<r>).
# Nouns carry [m]/[f]/[m pl]; verbs carry the preposition they require.
#
# NOTE ON COGNATES. This domain is overwhelmingly Latinate, and rule 7 removes most of it:
# théorie, hypothèse, analyse, concept, notion, abstraction, structure, système, logique,
# rationnel, empirique, probabilité, énergie, masse, molécule, conscience, mémoire, identité,
# métaphore, ironie, doute, certitude, justice, liberté, nécessité, obstacle, perspective
# — all guessable from English, all omitted. What remains below is the part a learner
# cannot guess: native French abstract vocabulary, false friends, and the connectors and
# turns of phrase that actually carry an argument in French.
#
# Three roots are marked in parentheses because another file holds a same-spelled homonym:
# or (logique) vs or = gold, and voile (tissu) vs voile = sail.
