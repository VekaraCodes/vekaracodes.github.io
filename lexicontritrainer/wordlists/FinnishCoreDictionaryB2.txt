# SUOMEN KIELEN B2-SANASTO — VERBIT (itsestään selittyvä sanakirja)
# Finnish B2 verb glossary — self-explanatory dictionary
# =====================================================================
#
# RIVIN MUOTO / ENTRY FORMAT (yksi merkitys per rivi / one sense per line):
#   ilman kantaa:  sana<w>määritelmä<d>translation, translation<t>
#   kannan kanssa: sana<w>kanta<r>määritelmä<d>translation, translation<t>
#
#     sana        : hakusana (verbi perusmuodossa); rektio hakasulkeissa vain, jos ei partitiivi
#     kanta       : kantasana; MERKITÄÄN VAIN, jos verbi on siitä aidosti johdettavissa
#     määritelmä  : neutraali suomenkielinen selitys sanakirjatyyliin
#     translation : englanninkielinen vastine; useat pilkulla; verbit merkitään sanalla "to"
#
# PERIAATTEET / PRINCIPLES:
#   1. Määritelmä EI sisällä hakusanaa, sen kantaa eikä mitään saman perheen johdosta.
#   2. Käytetään mahdollisuuksien mukaan sanoja, jotka on määritelty muualla → suljettu sanasto.
#   3. Kanta annetaan vain läheiselle, samamerkityksiselle johdokselle (valmistaa ~ valmistua,
#      kasvaa ~ kasvattaa). Kaukaisia etymologisia yhteyksiä ei merkitä (pysyä ~ pysähtyä), eikä
#      kantaa merkitä silloin, kun johdoksen merkitys ei enää seuraa kannasta (onni ~ onnistua,
#      kirja ~ kirjoittaa) tai kun johdoksella on vakiintunut eri merkitys (imeä ~ imettää;
#      sen sijaan imeä ~ imeytyä kelpaisi). Jos kantasana on itse verbistä johdettu
#      (laulaa → laulu), kantaa ei merkitä.
#   4. Yksi merkitys per rivi: eri merkitykset saavat omat rivinsä (kääntää = turn / translate).
#      Saman logiikan kielikuva EI saa omaa riviä (siirtää = move / transfer / postpone).
#   5. Vieraslainoja vältetään; suositaan omaperäisiä sanoja myös määritelmissä.
#   6. Partitiiviobjekti on oletus, eikä sitä merkitä. Muut rektiot merkitään.
#   7. Sanasto lähtee suomen kielen käsitteistä, ei englannin sanojen käännöksistä: mukana ovat
#      esim. jaksaa, viitsiä, ehtiä, kelvata, pärjätä sekä tunnekausatiivit (väsyttää, naurattaa,
#      hävettää, palella, huimata) ja arjen sanat (saunoa, hiihtää, poimia, tuulettaa).
#
# JÄSENNYS / ORGANIZATION: verbit on ryhmitelty merkityksen mukaan aihepiireihin;
# aihepiirin sisällä aakkosjärjestyksessä. '#'-alkuiset rivit ovat kommentteja.
#
# REKTIOLYHENTEET / RECTION ABBREVIATIONS (partitiivi = oletus, ei merkitä):
#   illat.=illatiivi  elat.=elatiivi  allat.=allatiivi  abl.=ablatiivi
#   transl.=translatiivi  ess.=essiivi  gen.=genetiivi  iness.=inessiivi  ade.=adessiivi
#   inf.=A-infinitiivi  MA-inf.=MA-infinitiivi (esim. -maan, -masta)
#   impers.=persoonaton (tunnekausatiivi, esim. minua väsyttää)
