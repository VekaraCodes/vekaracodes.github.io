# GLOSARIO ESPAÑOL B2 — autoexplicativo
# Formato: palabra<w>raíz<r>definición<d>traducciones<t>
# Sin <r> = la palabra es su propia raíz.
# [m] [f] = género, solo cuando NO se deduce de la terminación
#   (se dan por sabidos: -o = m, -a / -ción / -sión / -dad / -tad / -tud = f).
# [de] [a] [con] = preposición que rige el verbo.
# Los cognados transparentes (información, importante, decidir...) se omiten como
# entradas, pero pueden usarse en las definiciones.
# Orden: primero la clase de palabra (verbos, adjetivos, sustantivos, otras),
# dentro de cada clase por grupos lógicos, y dentro de cada grupo por utilidad.
